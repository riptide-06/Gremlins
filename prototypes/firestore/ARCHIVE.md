# Firestore prototype archive

Preserved from commit `c847769`, before the Campus Cubbies rewrite.
`cloud_app.py` is the committed Firestore implementation, not the newer file
that previously occupied that path in the working tree.

The original README, deployment records, configuration example, tests, client,
and container/upload configuration are historical snapshots. Their root-relative
commands and deployment assertions describe that revision, not Campus Cubbies.
The SLIM gateway and its documentation now live in `../slim/`; the archived
app and tests still assume they are sibling files. Shared dependencies remain
at the repository root. This archive is not maintained as a runnable target.
