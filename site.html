Bring your own agent

      
The chat on this site is one way in. Any agent you already use can talk to your gremlin. Same cubby, same wall, same citations. Three ways, pick one.

    

    

      your agent
      
      your gremlin
      
      the wall
      
      
      Your gremlin reads your cubby with your login. The wall strips everything a department isn't allowed to see and checks every citation on the way back. Gremlin to gremlin runs over A2A, with SLIM transport where a node is up.
    

    

      

        
1Claude Desktop or Claude Code

        Pair your agent with Campus Cubbies first (its guide is at cubby.bayleaf.dev/SKILL.md); that gives it a private token. Then add this server with the token as the bearer.
        
{"mcpServers": {"gremlin": {"url": ".../mcp"}}}

        Then ask Claude: "Using the gremlin tools, can I drop to 12 units this quarter?"
      

      

        
2A local model or any MCP client

        Run the gremlin on your own laptop. Your cubby stays in your Drive; set the two variables and it reads it from there.
        
git clone https://github.com/riptide-06/Gremlins
cd Gremlins && uv sync
export CUBBY_URL=https://cubby.bayleaf.dev CUBBY_TOKEN=...
BOX_STORE=cubby uv run mcp_server.py    # stdio

        Works with any MCP-capable client, including local models.
      

      

        
3Talk to a department directly (A2A)

        Every department gremlin is an A2A 1.0 agent with skill answer. Discover the card, send the question and the context you choose to share.
        
uv run dept_gremlin.py serve --dept iso --port 10001
GET /.well-known/agent-card.json
SendMessage {"session_id","question","context"}

        Stateless. Every claim cites a box id. Escalation is decided in code.
